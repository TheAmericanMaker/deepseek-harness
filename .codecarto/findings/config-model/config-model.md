# Configuration Model

## 2026-08-19 — architecture phase

### Composition model
A running `dsh` is a plugin tree composed at boot from ordered layers:
1. Each bundle in the profile's listed order (`dsh.profile` lists bundles).
2. The profile's `cordis.patch.yml`.
3. The home-level patch.
4. Any `--patch` overlay.

A **bundle** is a distribution format for Cordis config rows + the code they mount (`dsh.bundle` points at a patch file). A **profile** is a named composition stored in the harness home.

### Patch semantics
A patch targets a row by id and replaces its whole config, or inserts new rows. `!!js` (never `!js`) is allowed under plugin `config` and entry `disabled`; other metadata stays literal. Conditional composition uses overlays. The vendored `include` plugin's `applyEntryPatches` (local modification 11) indexes each `insert`ed entry as it is added, so a later patch can configure/disable a row an earlier patch inserted.

### Config interpolation
`disabled: !!js` evaluates against the loader context at every mount decision (local modification 18). Lazy Loader config resolution (local modification 15) resolves raw fiber config through `internal/config` only after declared injections are active.

### Environment / precedence
- Harness home precedence (highest first): explicit configured path → `$DSH_HOME` → `~/.dsh`. Empty/whitespace `$DSH_HOME` treated as unset.
- Credentials: env-over-`.env` provider.
- `DEEPSEEK_API_KEY`, `DEEPSEEK_BASE_URL` for real-API tests/demos.

### Generated config catalog
`docs/config-catalog.md` is generated by `scripts/gen-config-catalog.ts` (freshness-gated in CI).

## 2026-08-19 — contracts phase

Contract-level config additions:
- Credential precedence (most→least trusted): inherited process env > `$DSH_HOME/.credentials.yaml` > `<cwd>/.env` > `$DSH_HOME/.env`.
- Tool config examples: `enableRunInBackground` (bash/pwsh, default true), `packChunks` (JSONL, default true), `compression` (zstd|none, default zstd), `watch`/`debounceMs` (credentials, default true/100), `allowParallelInProgress` (todo_write, required no default).
- `disabled: !!js` per-entry interpolation; `!!js` (never `!js`) under plugin `config` and entry `disabled`.

## 2026-08-19 — protocols phase

Protocol-level config additions:
- SDK `initialize` params: `cwd`, `provider`, `model`, `maxTokens?` (positive output-token cap inherited by SDK-created agents).
- ACP config: `provider`, `model`, `stream?` (runtime-only transport override; production uses stdio).
- JSONL config: `root` (required, no default), `packChunks` (default true), `compression` (zstd|none, default zstd), `preparedSessionCacheSize`, `writeBatchMaxDelayMs`.

## 2026-08-19 — porting phase

Synthesis-level config additions:
- The layered composition model (bundles → patches → overlays) is a core porting priority; the vendored Include/Loader/HMR reconcile config transactionally.
- `!!js` interpolation and `disabled: !!js` per-entry evaluation must be preserved for parity.
